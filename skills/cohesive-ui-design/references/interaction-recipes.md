# 有关联的克制交互

只为适合表达氛围或关系的区域采用这些做法。任务密集、长时间阅读或需要快速扫描的区域，优先使用静态层级与简短状态反馈。

## 先定义对象和状态

先写清楚控制对象、被反馈对象和两者的关系。展示区内自由移动可以以指针为目标；选项、卡片和键盘焦点则应映射到对应内容对象。装饰本身不增加可聚焦控件。

| 状态 | 视觉职责 | 退出或切换 |
| --- | --- | --- |
| 静止/环境态 | 可选择低频、低对比的分散漂移与呼吸，也可完全静止 | 有明确输入时弱化背景随机性 |
| 进入/靠拢 | 保留来源的运动连续性，让人看出它们正在合并 | 随时可反向，不重新生成一批对象 |
| 自由跟随 | 一个主要反馈区域跟随指针，背景运动更弱 | 到语义控件时转向内容目标 |
| 语义聚焦 | 选项、卡片、键盘焦点共同指向同一内容对象 | 目标改变时从当前视觉位置继续移动 |
| 离开/散开 | 逐步恢复已认可的环境状态 | 不突然消失，也不残留选中装饰 |
| 减少动态效果/触屏 | 用静态选中、描边或局部明暗表达必要信息 | 不要求用户完成悬停或观看动画 |

选中状态与瞬时悬停的优先级由当前产品决定。明确写出规则，避免键盘焦点、指针和自动播放相互抢夺目标。

## 多个光团汇聚为一个

适合需要柔和空间反馈的展示区域。圆形、发散和单色聚焦都是这个做法的目标，不要求用于所有界面。

1. 保留分散状态已接受的配色、轨迹和呼吸。靠拢使用连续的位置与尺度，不在进入时重建随机状态。
2. 让分散光团先向目标移动，再将可见性平滑交接给一个独立的汇聚光晕。单光晕的位置和大小可以从当前光团的加权状态开始，避免交接瞬间跳到新中心。
3. 汇聚光晕使用同一色相，由中心向外降低透明度；外缘柔化。不要依靠多个异色光团叠加来制造最终颜色，也不要让渐变停点引入额外的黄边或其他色环。
4. 汇聚完成时，原光团的可见贡献归零。若光团同时照亮线条，其照明蒙版也完成同样的交接；仅隐藏颜色层可能仍留下多重亮度边界。
5. 调整交接时的总亮度和尺寸，让中途不突然变暗、变亮或收缩。弱呼吸可由同一个汇聚光晕的透明度或半径表达。
6. 散开反向完成交接，恢复原分散色系；快速进入、退出、连续移向新目标仍从当前进度继续。

实现不限定 CSS、SVG 或 Canvas。选现有栈能稳定完成的方案；简单径向渐变和一次动画循环足够时，不新增粒子引擎。

## 颜色或空间出现硬分界时

将效果单层显示，逐一恢复背景、蒙版、伪元素与前景装饰，判断是哪一层造成可见边界。

- 检查同一光晕下的底色是否被另一容器、斜面或遮罩切成两块。
- 检查渐变在透明端是否保持同一底色定义、混合模式是否改变色相，以及滤镜边界是否被裁掉。
- 检查交互区域、渲染区域和目标坐标是否来自同一个稳定祖先；包含视觉上属于该区的侧边留白。
- 必要时在聚焦态淡出冲突装饰，退出后恢复。优先修正冲突层的责任，避免不断增强光效来盖住它。
- 在区域左侧、中心、右侧和外边缘，以及选项切换时分别观察；某一张居中截图没有接缝不代表所有位置都正常。

## 用线条表达关系

先区分业务数据线与装饰线。地图路线、图表曲线和流程边保留业务含义与完整性；下面的数量和长度取舍主要针对装饰纹理。数据聚合或筛选需要独立的产品依据，不能由美化需求推导。

主线表达真实关系，始终连接到相关图形的端点。缩放、选中或悬停改变亮度时，几何连接仍完整。

支线只是次级纹理时，保持短、稀疏、有明确的折转与收尾。不要沿每个节点复制一套等长平行线，也不要用一条长线填完所有空白。是否交叉根据关系可读性决定；减少无意义的交叉，但不为绝对不交叉制造更难看的绕路。

用光照或局部明暗逐渐揭示已有线条，避免鼠标每动一下就新增路径。正文和主要操作保持干净。科技主题可以使用布线语汇，其他行业应改用适合其内容的表达，或不用连线。

## 同一种巧思的轻量替代

- 表格：悬停某行时同步突出其详情标题或图表记录，不在数据背景播放粒子。
- 文档：目录焦点与段落位置对应，搜索结果与正文命中同步；不要让正文随指针漂移。
- 多步骤流程：保存当前输入并平滑展示相关下一步，过渡帮助保持位置感。
- 作品或展品：选择缩略图时，主展示对象和说明协同变化，可用少量材质或边缘光。

## 实现与观察

先复用平台能力或已有动画方案。不要为单一装饰逐帧触发整个 UI 重渲染；长循环在后台、离屏或减少动态效果时停止，卸载清理事件与临时样式。静态装饰不截获点击。

检查静止、进入、聚焦、目标切换、离开、快速打断、窗口变化和键盘/触屏路径。自动检查可以证明只有一个最终可见光层、目标位置正确或循环停止；过渡是否舒服仍需实际观看。
